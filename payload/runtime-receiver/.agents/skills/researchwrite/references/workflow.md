# ResearchWrite workflow

## Compose

1. Freeze the scope, target reader, research field, language, and deliverable.
2. Extract the research canon and terminology from supplied materials.
3. Create the evidence table before proposing the argument.
4. Frame one central research question and one defensible thesis.
5. Map each section to a purpose and an evidence contract.
6. Draft from the contracts, then run QA and revise only failed dimensions.

## Revise

1. Preserve the original draft and identify the exact revision scope.
2. Extract every material claim from the affected text.
3. Map claims to supplied evidence and flag overstatement or missing support.
4. Diagnose argument, method, feasibility, terminology, and prose defects.
5. Produce the smallest coherent revision and a concise change rationale.

## Hybrid

1. Classify paragraphs as keep, edit, rebuild, or remove.
2. Reuse only text that fits the rebuilt evidence and argument maps.
3. Rebuild weak sections from contracts instead of polishing unsupported prose.

## Output organization

Use a task-local folder selected by the user. Keep the authoritative Markdown and
QA artifacts together. Do not write to a Vault or archive unless separately
authorized. If export tooling creates DOCX/PDF, keep generated files separate from
the source Markdown and preserve the original input.
